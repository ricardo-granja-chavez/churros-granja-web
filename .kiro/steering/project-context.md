# Contexto del Proyecto

## Descripción General

Aplicación web para Churros Granja desarrollada con tecnologías modernas de desarrollo frontend.

## Stack Tecnológico

- **React 18.3**: Biblioteca de UI para construcción de interfaces
- **TypeScript 5.9**: Superset de JavaScript con tipado estático
- **Vite 5.4**: Herramienta de desarrollo y compilación ultra-rápida
- **Tailwind CSS 3.4**: Framework CSS utility-first para estilos

## Estructura del Proyecto

```
churros-granja-web/
├── src/
│   ├── assets/         # Recursos estáticos (imágenes, iconos, fuentes)
│   ├── components/     # Componentes React reutilizables
│   ├── pages/          # Componentes de página completa
│   ├── styles/         # Archivos de estilos globales
│   ├── types/          # Definiciones de tipos TypeScript compartidos
│   ├── App.tsx         # Componente raíz de la aplicación
│   ├── main.tsx        # Punto de entrada de la aplicación
│   └── vite-env.d.ts   # Definiciones de tipos para Vite
├── index.html          # HTML principal
├── vite.config.ts      # Configuración de Vite
├── tsconfig.json       # Configuración de TypeScript
├── tailwind.config.js  # Configuración de Tailwind CSS
└── postcss.config.js   # Configuración de PostCSS
```

## Referencia de Diseño

El diseño visual está definido en Figma y es la fuente de verdad para la interfaz de usuario.

**Importante**: No inventar elementos visuales. Todos los componentes, colores, tipografías e iconos deben provenir del diseño de Figma.
